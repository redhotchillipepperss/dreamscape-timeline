# Your media

Drop files here, then point to them in `src/data/story.ts`.

- `public/media/photos/`  → use as `/media/photos/your-photo.jpg`
- `public/media/videos/`  → use as `/media/videos/your-clip.mp4`
- `public/media/audio/about-you.mp3` → the background song

Everything else (dates, titles, letters, reasons, messages) is edited in
`src/data/story.ts` — that single file controls the whole experience.
